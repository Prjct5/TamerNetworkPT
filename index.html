about

I started learning networking with KAAAM Academy's CCNA course. After finishing the basics (static routing, VLANs, ACLs, HSRP, DHCP), I wanted to build something on my own — a full enterprise topology, configured and verified layer by layer.

topology

  • HQ Core — dual Layer-3 switches, inter-VLAN routing, HSRP gateway redundancy across 6 VLANs
  • HQ Access — port security, 802.1Q trunking with a hardened dedicated native VLAN
  • HQ Edge Router — connects HQ core out to the Data Center and the wider WAN
  • Data Center — separate site, backend servers, integrated into the OSPF backbone
  • Branch A / Branch B — remote sites physically deployed and addressed, awaiting WAN integration

build status

  • HQ core & access — VLANs, trunking, port security
  • HSRP gateway redundancy, verified active/standby failover
  • Data Center site integration
  • OSPF backbone convergence (Area 0)
  • Site-to-site VPN out to Branch A / Branch B
  • NAT/PAT for internet-facing access
  • Centralized DHCP / DNS
  • IPv6 dual-stack overlay

verification, not just configuration

Every stage was checked with real IOS output before moving to the next — not assumed to work because the commands were typed.
